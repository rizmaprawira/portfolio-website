8. Useful code/data feature: real postal CSV table, searchable five-row sample, source and limitation; visible approved AI disclosure and short planned/draft links.

Typography: system sans (Arial/Helvetica stack), bold headings; no font downloads or extra family. Hero name ~64px desktop, 46px mobile; section names ~36–40px; body 16px; metadata 13px. White dominant, #17191C ink, #59616B secondary; #DDECF8 framing/active learning states; #F8E2E5 smaller note/teaching moments. Radius 8–12px only where helpful. Existing figure viewer reused.
